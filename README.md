# ario-v2

نرم‌افزار جامع مدیریت فروشگاه، انبار و حسابداری آریو

## پشته فنی (Tech Stack)
- **Backend:** NestJS, TypeScript, MongoDB (Mongoose)
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Containerization:** Docker, Docker Compose

## راه‌اندازی (Development)
```bash
npm install
npm run dev
```

## تولید کارگاهی

از «بیشتر ← تولید کارگاهی» یا مدیریت کالاها، مواد مصرفی و محصول خروجی را انتخاب کنید. محصول جدید را با موجودی اولیهٔ صفر تعریف کنید؛ ثبت تولید موجودی آن را افزایش می‌دهد. هزینهٔ بسته‌بندی و اجرت برای کل نوبت تولید است و قیمت فروش برای هر واحد خروجی وارد می‌شود. مبالغ به تومان هستند. پیش‌نمایش هزینه بر اساس قیمت خرید فعلی است؛ گزارش سود هزینهٔ مواد را به ترتیب خریدهای انبار محاسبه می‌کند.

تغییر موجودی کارگاه در `stockAdjust` ذخیره می‌شود و در بازسازی موجودی باقی می‌ماند. سوابق تولید در `workshopbatches` ذخیره و همراه سایر مجموعه‌ها پشتیبان‌گیری می‌شوند. ثبت با شناسهٔ درخواست از کسر دوباره جلوگیری می‌کند. برای MongoDB مستقلِ پیکربندی فعلی، عملیات نیمه‌تمام با نشانگر روی کالاها هنگام راه‌اندازی یا تکرار همان درخواست بازیابی می‌شود. این بازیابی برای اجرای یک نمونه از بک‌اند، مطابق Docker Compose پروژه، طراحی شده است.

آزمون‌ها با `npm test --prefix backend -- --runInBand` اجرا می‌شوند. آزمون کارگاه یک MongoDB موقت و مستقل اجرا می‌کند؛ `mongod` باید روی PATH باشد یا مسیر آن با `MONGOD_BINARY` تنظیم شود. داده‌های برنامه در این آزمون‌ها استفاده نمی‌شوند.

## بررسی کارایی صفحهٔ فروش

`node scripts/check-pos-performance.cjs` ترتیب دسته‌ها و کالاها، جست‌وجوی فارسی و قالب‌بندی قیمت‌ها را بررسی می‌کند و یک بنچمارک مصنوعی نمایش می‌دهد. اعداد بنچمارک زمان بارگذاری واقعی روی گوشی نیستند. صفحه‌ها به‌صورت جداگانه بارگذاری می‌شوند؛ فروش اطلاعات جاری کالاها را از `/api/products/pos` می‌گیرد و سابقهٔ قیمت‌ها را دانلود نمی‌کند. موجودی و قیمت فروش در حافظهٔ کلاینت کش دائمی نمی‌شوند.
